# 大模型概念与宏观热点选股：学习笔记

> 原文：华泰研究《大模型概念与宏观热点选股》，2026-02-28。  
> 作者：沈洋、何康。  
> 主模板：Agent 与 AI 投研。  
> 辅助模板：策略与组合研究——月度概念与宏观热点组合仅用于检验多智能体研究工作流是否能稳定转化为选股结果，不作为并列主线展开。  
> 本笔记重点分析概念选股与宏观热点选股两套 LangGraph 多智能体架构、RAG 知识调用、产业链与宏观逻辑拆解、并行 Worker、证据评审、组合生成、Point-in-Time 回测，以及系统在可审计性、可复现性、风险约束和模型漂移方面的有效边界。  
> 仅作研究学习笔记，不构成投资建议。

---

## 一、快速总结

### 1. 一句话总结

报告将概念题材和宏观事件选股拆解为规划、逻辑推演、并行研究、证据仲裁和组合生成等多智能体节点，使大模型从一次性股票推荐器升级为具备产业链深挖、反证约束和结构化输出的自动投研工作流。

### 2. 研报类型

- **主类型：Agent 与 AI 投研。**
- **主要研究对象：** 概念主题和宏观事件驱动下的 A 股自动化研究流程。
- **最终交付：** 结构化投资逻辑、候选股票池、核心/卫星/对冲分层、触发条件、失效条件、研究报告和月度组合。
- **主要技术：** LangGraph、Gangtise 知识库 RAG、DeepSeek、结构化 Prompt、并行 Agent、Evidence Reviewer/Judge。
- **主要验证：** 月度滚动提取概念和宏观热点，调用智能体选股，构建等权组合并与沪深 300 和万得偏股混合型基金指数比较。
- **核心价值：** 将容易受主观叙事和单一路径偏差影响的主题研究，转化为职责分离、结果复核和证据约束的自动化流程。

### 3. 报告试图解决的核心问题

概念和宏观热点投资并不缺信息，真正困难的是信息结构复杂且快速变化：

1. 概念标签通常模糊，如何从题材名称追溯至完整产业链；
2. 同一概念包含核心供应商、系统集成商、应用端和生态服务商，如何避免仅凭关键词推荐股票；
3. 宏观事件对 A 股的影响存在外部、内部、市场与配置等多条路径，如何避免只沿一条叙事推演；
4. 大模型会生成看似合理但证据薄弱的结论，如何进行一致性、时效性和相关性审核；
5. 多个研究节点的结果可能冲突，如何保留冲突而不是强行生成一致答案；
6. 如何把自然语言研究结果转化为可执行、可回测的月度股票组合；
7. 多智能体带来的性能改善究竟来自任务分工、RAG、证据评审，还是主题行情本身。

### 4. 两套多智能体框架

报告构建了两条相对独立但结构相似的工作流。

#### 概念选股工作流

```text
概念主题 + 补充提示
        ↓
planner：定义研究边界、假设、风险与产业链提示
        ↓
chain_analyzer：拆分 4-8 个一级产业链环节
        ↓
多个 node_expander 并行：
检索 RAG、解释环节价值、推荐代表性公司
        ↓
evidence_reviewer：
检查深度、覆盖、股票相关性、重复与冲突
        ↓
portfolio_builder：
去重、分层、给出权重、触发与失效条件
        ↓
validate_and_save：
A 股代码校验，保存 Excel 与 Markdown
```

#### 宏观热点选股工作流

```text
宏观事件 + 持有期/风险偏好
        ↓
planner：识别事件类型并生成研究任务
        ↓
infer_logics：引入可解释的传导逻辑
        ↓
run_worker 并行调用：
macro / sector / stock / risk
        ↓
evidence_judge：
评价强度、时效、共识度、可执行性与冲突
        ↓
portfolio_builder：
合并不同逻辑、去重、生成组合与研究报告
        ↓
validate_and_save：
A 股校验与文件保存
```

### 5. 主要结论

- 单一大模型适合文本理解，但复杂投研任务需要把规划、研究、反证和组合决策分开执行。
- 概念选股的核心增量不是识别“概念相关公司”，而是先把概念拆成 4-8 个具有经济含义的产业链环节，再分别完成 RAG 检索和股票映射。
- 宏观热点选股不以产业链为主，而是并行验证宏观解释、行业映射、候选股票和风险反证，重点约束单一路径叙事。
- Evidence Reviewer/Judge 是两套架构的关键节点，用于发现证据不足、产业链遗漏、结果冲突、信息过期和股票映射牵强。
- 报告通过严格的自然月信息截断构建月度投资依据，理论上避免直接使用月末之后的信息。
- 月度概念组合在 2022-12-30 至 2026-02-13 的年化收益约为 45.06%，Sharpe 比率约为 1.21，相对沪深 300 的年化超额收益约为 38.23%，信息比率约为 1.33。
- 概念组合最大回撤约为 54.40%，说明高收益伴随显著主题 Beta、拥挤和风格回撤，不能将回测结果简单归因于智能体推理。
- 月度宏观热点组合年化收益约为 22.60%，Sharpe 比率约为 1.04，相对沪深 300 的年化超额收益约为 15.51%，信息比率约为 1.30。
- 宏观热点组合最大回撤约为 29.29%，明显低于概念组合，收益路径也更平稳。
- 概念组合更像高弹性的主题轮动策略；宏观热点组合更像由事件逻辑驱动的大盘风格配置。
- 报告未给出与单 Agent、关键词检索、人工研究和去除证据评审节点的严格消融实验，因此多智能体本身的独立贡献仍未被识别。

### 6. 最值得关注的创新与价值

1. **主线明确：** 将多智能体用于投研流程治理，而不是只让多个模型重复荐股。
2. **概念研究产业链化：** 通过 chain analyzer 避免概念与公司之间的浅层关键词映射。
3. **宏观研究多路径化：** 将宏观、行业、股票和风险反证并行展开。
4. **证据仲裁显式化：** 评价证据强度、时效、共识和可执行性，并记录冲突。
5. **结构化输出：** 节点间使用 JSON，使中间状态可传递、校验和保存。
6. **时间截断意识：** 月度材料不晚于当月末，具备 Point-in-Time 研究意识。
7. **从研究到组合闭环：** 不停留在案例展示，而是将工作流落地为月度回测。
8. **两类任务使用不同路由：** 概念选股强调产业链纵深，宏观热点强调因果传导和反证，不用同一模板硬套所有问题。

## 二、主模板路由与分析边界

### 1. 为什么主模板是 Agent 与 AI 投研

报告篇幅的核心集中在：

- LangGraph 图结构；
- Agent 角色划分；
- Prompt 和 JSON 输出；
- RAG 调用；
- 并行节点；
- 证据审核；
- 结果保存。

组合回测是对系统输出质量的下游检验，而不是报告的唯一贡献。真正的新方法是研究工作流，因此主模板应当是 **Agent 与 AI 投研**。

### 2. 为什么策略与组合是辅助模板

报告确实给出：

- 月度概念组合；
- 月度宏观热点组合；
- 等权配置；
- 沪深 300 与基金指数基准；
- 收益、波动、回撤、信息比率和换手率。

但它没有系统研究：

- 最优持仓数量；
- 权重优化；
- 行业与风格中性；
- 风险预算；
- 单票约束；
- 组合止损；
- 容量和冲击成本。

因此，组合研究只用于验证 Agent 输出是否具有投资价值。

### 3. 不应把回测收益全部写成“LLM Alpha”

回测结果至少混合了四部分：

```text
主题与宏观事件本身的 Beta
+
月度热点筛选能力
+
产业链或逻辑映射能力
+
股票与组合构建能力
```

若缺少单 Agent、固定规则、人工主题组合和随机主题组合等基线，就不能确认 45.06% 年化收益中有多少来自多智能体协作。

## 三、研究背景：概念和宏观热点为何适合多智能体

### 1. 信息量大，但边界模糊

概念题材具有以下特征：

- 名称高度概括；
- 公司关联程度不同；
- 上游、中游和下游逻辑不同；
- 核心业务与“蹭概念”并存；
- 主题边界随技术和产业进展变化。

宏观事件则具有：

- 信息来源分散；
- 传导链条长；
- 预期与事实可能相反；
- 影响期限不一致；
- 同一事件对不同资产方向不同。

单一 Prompt 很容易把复杂问题压缩成一个顺畅但缺乏约束的故事。

### 2. 单 Agent 的典型失效

单 Agent 通常同时承担：

- 界定问题；
- 搜索材料；
- 推演逻辑；
- 选择行业；
- 推荐股票；
- 判断风险；
- 生成组合。

这会产生：

1. **任务拥挤：** 上下文过长，关键约束被忽略；
2. **确认偏差：** 前面生成的观点影响后续检索和论证；
3. **缺少独立审核：** 生成者同时成为评审者；
4. **错误传播：** 早期误判贯穿最终组合；
5. **输出不稳定：** Prompt 或模型轻微变化导致股票池大幅变化；
6. **不可审计：** 无法定位错误发生在哪一阶段。

### 3. 多智能体的合理价值

多智能体并不意味着“多个模型投票”。更合理的设计是：

- 每个节点拥有清晰职责；
- 输入输出格式固定；
- 分析路径并行；
- 汇总前必须审核；
- 冲突被显式记录；
- 中间结果可以独立评估和重跑。

报告的两套系统总体符合这种工作流思路。

## 四、数据、模型与工具层

### 1. LangGraph

LangGraph 负责：

- 编排节点；
- 传递状态；
- 控制并行任务；
- 汇总结果；
- 输出结构化文件。

报告的流程图说明系统采用有向工作流，而不是自由对话式多 Agent。

### 2. Gangtise RAG

两套智能体均依赖 Gangtise 知识库，内容包括：

- 研究报告；
- 公司公告；
- 产业公众号和公开材料；
- 宏观事件与行业资料。

RAG 的作用是：

- 为研究计划补充历史背景；
- 为产业链拆分提供依据；
- 为公司推荐提供业务证据；
- 为宏观逻辑提供事件材料。

### 3. DeepSeek

DeepSeek 用于：

- 月度候选概念和宏观热点进一步筛选；
- 多个节点的语言理解和逻辑生成；
- 结构化 JSON 输出；
- 组合和研究报告总结。

报告未披露具体模型版本、温度、采样参数和版本冻结方式。

### 4. Wind

Wind 主要用于：

- A 股代码和公司信息；
- 市值；
- 价格与回测数据；
- 基准指数；
- 股票代码校验。

### 5. 数据层的核心风险

- Gangtise 为专有知识库，第三方难以复现；
- RAG 的文档版本、入库时间和检索排序未披露；
- DeepSeek 版本可能更新，历史结果难以重现；
- 公告和研报可能在后期修订或重新入库；
- 不同数据源的发布日期与可用日期需要分别记录。

## 五、概念选股智能体：总体架构

报告第 6 页的 LangGraph 架构包含七类节点：

| 节点 | 主要作用 |
| --- | --- |
| `planner` | 界定概念、生成研究计划 |
| `chain_analyzer` | 将概念拆成 4-8 个产业链环节 |
| `node_expander` | 并行分析各环节并筛选股票 |
| `evidence_reviewer` | 检查证据、覆盖、相关性和冲突 |
| `portfolio_builder` | 汇总股票、分层并构建组合 |
| `validate_and_save` | 校验 A 股代码并保存文件 |
| `START/END` | 管理工作流起止 |

系统输入包括：

- `user_query`：概念主题；
- `user_prompt`：补充研究约束。

系统输出包括：

- 概念股票清单；
- 研究报告；
- Excel 与 Markdown 文件。

---

## 六、概念节点一：研究计划 `planner`

### 1. 任务

`planner` 不直接推荐股票，而是输出：

- 概念主题的定义；
- 研究重点维度；
- 投资逻辑假设；
- 产业链拆分提示；
- 风险因素。

结构化结果可概括为：

```json
{
  "topic_summary": "概念定义与研究边界",
  "focus_dimensions": ["维度 1", "维度 2"],
  "investment_hypotheses": ["假设 1", "假设 2"],
  "chain_hint": "产业链拆分方向",
  "risk_factors": ["风险 1", "风险 2"]
}
```

### 2. 价值

该节点将“研究范围”与“股票推荐”分离，减少模型在没有定义概念边界时直接输出公司名单。

### 3. 潜在问题

- 概念定义仍由 LLM 生成；
- 研究计划可能从一开始就遗漏关键分支；
- 报告未展示规划失败后的回滚机制；
- `planner` 与后续节点使用相同知识库时，错误先验可能被重复强化。

---

## 七、概念节点二：产业链拆分 `chain_analyzer`

### 1. 任务

`chain_analyzer` 将概念拆分为 4-8 个一级环节，常见结构包括：

- 上游关键资源或核心材料；
- 核心零部件；
- 中游制造和系统集成；
- 软件、算法与平台；
- 下游解决方案；
- 测试、认证和标准；
- 销售、服务与生态运营。

### 2. 设计约束

报告强调：

- 一级节点应覆盖完整产业链；
- 节点不能过细；
- 环节之间不应重叠；
- 必须避免遗漏关键价值环节。

### 3. 核心价值

传统概念选股经常采用：

```text
概念关键词
→ 公司公告或业务描述含关键词
→ 直接纳入股票池
```

报告改为：

```text
概念定义
→ 产业链环节
→ 环节经济价值
→ 公司收入与竞争地位
→ 股票池
```

这一变化把“语义相关”升级为“产业链相关”。

### 4. 失效风险

- 产业链边界可能主观；
- 新兴产业常跨越传统行业分类；
- 环节数量 4-8 属于经验规则；
- 复杂概念可能需要二级节点；
- 过度强调完整产业链可能把低弹性环节也纳入。

---

## 八、概念节点三：并行展开 `node_expander`

### 1. 并行机制

每个产业链环节由一个独立 `node_expander` 处理：

1. 检索 RAG；
2. 解释该环节在产业链中的位置；
3. 判断市场规模和增长逻辑；
4. 推荐 5-10 家代表性 A 股公司；
5. 为股票给出逻辑和得分；
6. 标记为 `core` 或 `satellite`。

### 2. 结构化输出

```json
{
  "sub_industry": "产业链环节",
  "description": "环节作用与投资价值",
  "stocks": [
    {
      "name": "公司名称",
      "reason": "核心纳入逻辑",
      "score": 0.8,
      "bucket": "core"
    }
  ]
}
```

### 3. `core` 与 `satellite`

- `core`：概念的龙头或关键供应商，逻辑直接、业务贡献较高；
- `satellite`：弹性标的或细分领域公司，受益路径更间接、风险更高。

该分层有助于区分：

- 概念纯度；
- 业务确定性；
- 股价弹性；
- 组合中的角色。

### 4. 并行化的价值

- 不同环节独立检索，降低上下文拥挤；
- 允许同时扩展完整产业链；
- 局部节点可以独立重跑；
- 节点输出可以分别评分。

### 5. 并行化的风险

- 各节点可能重复推荐同一公司；
- 不同节点可能采用不同业务口径；
- 所有节点使用同一底层模型，错误相关性仍然较高；
- 并行输出增加 Token 和检索成本；
- 没有显示自适应停止条件，弱环节也可能被强行展开。

---

## 九、概念节点四：证据评审 `evidence_reviewer`

### 1. 评审维度

报告要求从以下方面审核：

1. 各产业链环节分析的深度和准确性；
2. 产业链覆盖是否完整；
3. 股票推荐是否合理且一致；
4. 是否存在重复股票和逻辑冲突；
5. 不同节点结果能否共同支撑概念投资逻辑。

### 2. 输出

```json
{
  "evidence_table": [
    {
      "node": "环节名称",
      "quality": 0.8,
      "coverage": 0.7,
      "stock_relevance": 0.9,
      "comment": "评审意见"
    }
  ],
  "gaps": ["遗漏环节"],
  "cross_node_duplicates": ["重复股票"],
  "confidence": 0.75
}
```

### 3. 关键价值

这是报告中最重要的治理节点之一。它试图把以下隐性判断显式化：

- 证据是否足够；
- 产业链是否完整；
- 股票与环节是否真正相关；
- 多个 Agent 是否发生冲突。

### 4. 关键不足

流程图中 `evidence_reviewer` 之后直接进入组合构建和保存，未明确展示：

```text
发现证据不足
→ 返回对应 node_expander
→ 补充检索
→ 再次评审
```

因此它更像评分器，而不是真正的闭环纠错器。

## 十二、宏观热点选股智能体：为何需要另一套架构

概念选股主要解决“某一主题包含哪些产业链和公司”，宏观事件则需要回答：

## 十四、宏观节点一：`planner` 与 `infer_logics`

### 1. `planner`

`planner` 首先使用 RAG 搜索事件背景，对用户问题初步归类，输出：

```json
{
  "query_type": "macro_event/concept/hybrid",
  "tasks": ["任务 1", "任务 2"],
  "workers": ["macro", "sector", "stock", "risk"],
  "strategy_logics": ["逻辑 1", "逻辑 2"]
}
```

### 2. `infer_logics`

`infer_logics` 根据关键词引入可解释的常见传导，例如：

- 利率下降 → 成长股估值扩张；
- 通胀上行 → 资源品受益；
- 汇率升值 → 外资流入与进口成本改善；
- 财政扩张 → 基建和顺周期需求上升。

### 3. 优点

- 将“逻辑假设”提前固定；
- 为不同 Worker 提供统一输入；
- 避免后续节点各自理解事件方向；
- 便于检查结论是否偏离原始逻辑。

### 4. 风险

- 预设逻辑可能过于简单；
- 关键词路由可能忽略非线性或二阶效应；
- 宏观因果关系高度状态依赖；
- 事件的实际影响可能与历史模板相反；
- 固定逻辑库可能成为系统认知上限。

## 十五、宏观 Worker 一：宏观解读

### 1. 输出内容

`macro worker` 负责：

- 事件本质；
- 核心驱动变量；
- 未来演化路径；
- 支持与反对假设；
- 宏观风险；
- 逻辑置信度。

### 2. 角色定位

该节点回答“为什么”，不直接推荐行业或股票。

### 3. 主要价值

- 将宏观结论表示为假设而不是事实；
- 强制输出风险和反向情形；
- 为行业映射提供上游因果变量。

### 4. 主要局限

- 宏观数据修订问题未被单独处理；
- 没有量化事件冲击大小；
- 没有给出概率分布或情景权重；
- 置信度仍由语言模型自评。

---

## 十六、宏观 Worker 二：行业映射

### 1. 任务

`sector worker` 从宏观逻辑推导行业影响，输出：

- 受益行业与风格；
- 受损行业与风格；
- 每个方向的传导理由；
- 置信度。

### 2. 从“因”到“果”

例如利率下降可能同时带来：

- 成长估值上升；
- 银行息差压力；
- 房地产融资改善；
- 汇率变化；
- 商品和风险偏好变化。

行业映射必须说明中间变量，而不是仅给出结果。

### 3. 失效风险

- 相同宏观变量对行业的影响会随估值和市场预期改变；
- 行业层面的 Beta 不等于个股收益；
- 海外事件到 A 股行业之间存在制度和资本流动差异；
- 行业方向可能已被市场提前定价。

## 十七、宏观 Worker 三：候选股票

### 1. 任务

`stock worker` 在既定投资逻辑下：

- 检索行业与公司材料；
- 筛选 5-10 只 A 股；
- 说明股票与逻辑的映射；
- 给出分数；
- 标记 `core`、`satellite` 或 `hedge`。

### 2. 相比概念股票节点的差异

该节点不再重新定义产业链，而是把股票映射到：

```text
宏观事件
→ 行业和风格
→ 可交易公司
```

### 3. 风险

- 同一公司可能因多条逻辑重复入选；
- 宏观受益不等于盈利受益；
- 个股选择可能混入大市值和流动性偏好；
- 缺少估值、盈利预测和风险暴露的量化校验。

## 十八、宏观 Worker 四：风险反证

### 1. 任务

`risk worker` 独立输出：

- 逻辑失效条件；
- 事件反转风险；
- 市场已定价风险；
- 回撤来源；
- 风险置信度。

### 2. 核心价值

将风险分析独立成 Worker，可以避免主逻辑节点只收集支持证据。

### 3. 主要问题

- 风险节点仍使用相同底层模型和知识库；
- 独立角色并不等于统计独立；
- 报告未说明风险结论是否能否决股票；
- 未展示风险触发后的组合降权或退出规则。

## 十九、证据仲裁 `evidence_judge`

### 1. 四个评价维度

报告第 17 页将证据评价拆成：

| 维度 | 含义 |
| --- | --- |
| `strength` | 证据是否直接支撑结论 |
| `freshness` | 信息是否反映最新宏观环境 |
| `consensus` | 不同 Worker 是否形成一致判断 |
| `actionability` | 逻辑能否转化为具体投资行为 |

### 2. 冲突识别

Judge 还需记录：

- 宏观判断与行业映射冲突；
- 股票选择与产业逻辑冲突；
- 风险反证与主逻辑冲突；
- 不同数据源之间的冲突。

### 3. 输出结构

```json
{
  "evidence_table": [
    {
      "claim": "结论",
      "strength": 0.0,
      "freshness": 0.0,
      "consensus": 0.0,
      "actionability": 0.0
    }
  ],
  "conflicts": ["冲突 1", "冲突 2"],
  "confidence": 0.0
}
```

### 4. 价值

该节点将“正确性”拆成证据、时间、共识和落地四个维度，优于单一置信度。

### 5. 伪共识风险

若多个 Worker：

- 使用相同模型；
- 使用相同 Prompt 风格；
- 检索相同知识库；
- 共享相同初始逻辑；

它们可能产生高度相关的答案。此时 `consensus` 只是同源模型的一致，而不是真正独立证据的一致。

## 二十、宏观案例：美联储主席变动

报告使用“美联储主席变动下应如何投资 A 股”作为测试问题，并限定：

- 持有期为 1-3 个月；
- 风险偏好为中等。

### 1. 外部逻辑

- 主席更替可能强化降息预期；
- 短期影响全球流动性和美元；
- 中美利差收窄与人民币升值可能推动外资回流；
- 中期政策路径仍可能出现分化。

### 2. 内部逻辑

- 国内货币环境相对宽松；
- 居民财富可能向金融资产再配置；
- 公募、险资等增量资金有望提供流动性支持；
- 人民币升值可能改善 A 股资金环境。

### 3. 市场逻辑

- 外部冲击短期改变风险偏好；
- 若海外政策预期逆转，海外流动性改善可能推升成长板块；
- 国内政策和产业催化可能使科技成长与中小盘相对占优。

### 4. 配置逻辑

报告采用“哑铃型”思路：

- 进攻端：AI、半导体、通信等科技成长；
- 防守端：消费、金融或基本面较稳的核心资产；
- 关注美国宏观数据、国内政策落地和成交量。

### 5. 案例评价

该案例较好展示多路径推演，但仍存在：

- 事件本身属于假设性问题；
- 具体结论依赖当时市场状态；
- 1-3 个月期限由用户给定而非模型估计；
- 股票推荐缺少真实事件后的前瞻验证；
- 案例不能证明长期自动选股有效。

## 二十一、月度投资依据构建

### 1. 月度滚动设计

报告从 2022 年 12 月起，以自然月为研究单位：

1. 收集当月公开信息；
2. 所有信息时间戳不得晚于月末；
3. 提取当月概念题材和宏观事件；
4. 对概念去重和细化；
5. 在下一月首个交易日前完成组合；
6. 月度调仓。

### 2. 概念与宏观热点的区别

#### 概念材料

要求：

- 能映射到明确产业链；
- 是细分主题，而不是宽泛行业标签；
- 具有可识别的 A 股公司集合。

#### 宏观热点

要求：

- 事件当月发生；
- 对 A 股具有明确传导方向；
- 避免长期叙事和模糊展望；
- 能形成可检验的投资逻辑。

### 3. 月度候选筛选

由于每月候选较多，报告调用 DeepSeek 进一步选择代表性最高的：

- 概念；
- 宏观热点。

筛选标准包括：

- 与当月市场主线的相关性；
- 是否具备明确 A 股产业链；
- 是否代表独立逻辑；
- 是否避免过度宽泛。

### 4. Point-in-Time 优点

报告明确限制信息不晚于当月末，这是避免前视偏差的必要条件。

### 5. Point-in-Time 仍需核验的问题

- RAG 文档的真实入库时间；
- 历史页面是否后续更新；
- 研报和公告发布日期是否与抓取日期一致；
- 月末后发布但回填为月末日期的材料；
- DeepSeek 和 RAG 是否在回测后重新运行；
- 历史知识库是否包含后来总结性的文档。

## 二十二、月度概念选股策略

## 二十三、月度宏观热点选股策略

### 1. 组合规则

报告的月度宏观热点策略为：

1. 每月选择 1 个最佳宏观热点；

3. 汇总结果并去重；
4. 每月至多持有 20 只股票；

## 二十四、概念策略与宏观策略对比

| 维度 | 概念策略 | 宏观热点策略 |
| --- | --- | --- |
| 研究对象 | 产业与技术主题 | 政策、利率、汇率与宏观事件 |
| 核心路由 | 产业链拆分 | 多路径因果推演 |
| 月度主题数 | 2 个概念 | 1 个宏观热点 |
| 最大股票数 | 30 | 20 |
| 年化收益 | 45.06% | 22.60% |
| 年化波动 | 37.14% | 21.73% |
| 最大回撤 | 54.40% | 29.29% |
| 相对沪深 300 月胜率 | 57.89% | 65.79% |
| 风格特征 | 高弹性主题成长 | 大盘、行业与宏观配置 |
| 主要价值 | 捕捉主题爆发 | 提高逻辑稳定性 |
| 主要风险 | 拥挤、反转、概念退潮 | 传导失真、预期提前定价 |

### 1. 概念策略的收益结构

更接近：

```text
少数大主题上涨
→ 集中获得高额收益
→ 在主题退潮期承受高回撤
```

### 2. 宏观策略的收益结构

更接近：

```text
宏观逻辑确定方向
→ 选择高流动性行业龙头
→ 提高月度命中率
→ 收益弹性较低
```

### 3. 两者不能直接比较“哪个 Agent 更强”

两类任务的：

- 股票池；
- 风格暴露；
- 主题数量；
- 持仓数量；
- 波动；
- 宏观环境；

均不同。绩效差异不能完全归因于架构差异。

## 二十五、研究难点

### 1. 概念边界动态变化

新技术会改变产业链，固定分类很快过时。

### 2. 宏观因果高度状态依赖

降息可能代表流动性改善，也可能代表经济衰退确认。

### 3. 非结构化证据质量不均

研报、公告、公众号和媒体材料的可信度与时效性不同。

### 4. 多智能体并不天然独立

同一模型和知识库可能产生相关错误。

### 5. 研究输出难以量化验证

“产业链完整”“逻辑合理”和“证据强”需要人工或标准数据进行外部校验。

### 6. 月度回测样本较短

约三年多历史无法覆盖完整市场周期。

### 7. 组合收益与研究质量难以拆分

一个主题组合上涨可能只是市场风格正确，不代表产业链研究准确。

## 二十六、创新点

1. **为概念和宏观事件设计两套不同的 Agent 路由。**
2. **将概念选股从关键词搜索升级为产业链分层。**
3. **通过多个 `node_expander` 并行完成产业链深挖。**
4. **将宏观、行业、股票和风险设置为独立 Worker。**
5. **使用 Evidence Reviewer/Judge 记录证据质量、时效和冲突。**
6. **用 JSON 约束节点输入输出。**
7. **在组合输出中加入触发条件和失效条件。**
8. **设置 A 股校验和文件保存节点。**
9. **采用自然月信息截断构建滚动回测。**
10. **同时以宽基和主动权益基金指数评价结果。**

## 二十七、优点

### 1. 工作流与任务匹配

不同任务使用不同分解方式，而不是统一使用“搜索—总结—荐股”。

### 2. 中间结果可见

每个节点输出结构化结果，便于定位错误。

### 3. RAG 与推理分离

知识库负责提供材料，Agent 负责组织和判断。

### 4. 风险反证进入主流程

宏观策略设置独立风险 Worker，避免只生成看多逻辑。

### 5. 证据评审进入组合之前

组合不是所有 Agent 输出的简单拼接。

### 6. 具备 Point-in-Time 意识

月度信息截断是金融回测的必要基础。

### 7. 结果不只展示个案

报告构建三年多月度回测，验证系统是否能持续输出。

## 二十九、AlphaLens：本报告的 Alpha 来源

### 1. Research Process Alpha

**核心逻辑：** 把复杂主题研究拆成多个职责明确的子任务。

**实现机制：**

- Planner；
- 产业链或逻辑路由；
- 并行 Worker；
- Evidence Judge；
- Portfolio Builder。

**价值来源：**

- 降低上下文拥挤；
- 提高研究覆盖；
- 提升工作流速度；
- 允许局部节点重跑。

**失效风险：**

- 多节点增加成本；
- 任务分解错误；
- 缺少闭环重试。

### 2. Information Processing Alpha

**核心逻辑：** 从大量非结构化材料中提取概念、产业链和宏观传导。

**实现机制：**

- Gangtise RAG；
- 大模型语义理解；
- 月度热点提取；
- 公司业务映射。

**价值来源：**

- 处理公告、研报与事件；
- 扩大研究覆盖；
- 捕捉传统结构化因子难以表达的信息。

**失效风险：**

- 数据过期；
- 检索偏差；
- 幻觉；
- 语义相关不等于盈利相关。

### 3. Decision Consistency Alpha

**核心逻辑：** 固定角色、Prompt、JSON 和评审规则，减少研究员在热点环境中的随意判断。

**实现机制：**

- 统一字段；
- 固定流程；
- 证据评分；
- 去重与校验；
- 触发和失效条件。

**价值来源：**

- 降低主题研究的主观波动；
- 使不同月份结果具有可比性。

**失效风险：**

- 固定模板僵化；
- 模型版本漂移破坏一致性。

### 4. Organizational Alpha

**核心逻辑：** 将产业链知识和宏观研究方法沉淀为可复用工作流。

**实现机制：**

- 知识库；
- 研究计划模板；
- Agent 角色；
- Markdown/Excel 输出；
- 结果保存。

**价值来源：**

- 降低研究对单一分析师的依赖；
- 提高跨团队知识复用。

**失效风险：**

- 知识库维护不足；
- 专有工具形成黑箱；
- 组织误把模型输出当作事实。

### 5. Prediction Alpha

**核心逻辑：** 月度选取市场主线并映射至股票组合。

**实现机制：**

- 概念提取；
- 宏观热点提取；
- 股票排序；
- 月度等权组合。

**价值来源：**

- 主题扩散；
- 政策和宏观预期差；
- 市场对产业链非核心环节反应不足。

**失效风险：**

- 热点已被定价；
- 主题退潮；
- 组合暴露于高 Beta 和动量反转。

### 6. Risk Management Alpha

**当前实现：**

- risk worker；
- Evidence Judge；
- 失效条件；
- 核心/卫星/对冲标签。

**实际效果：**

宏观策略回撤相对可控，但概念策略最大回撤仍超过 50%，说明风险信息尚未充分进入仓位和退出机制。

- 概念收入占比；
- 订单；
- 毛利率；
- 资本开支；

- 盈利预测。

- 利率；
- 汇率；
- 信用；
- 流动性；
- 风格因子。

可根据 Evidence Judge 分数和 risk worker 输出进行分级配置：

| 置信状态 | 组合处理 |
| --- | --- |
| 高证据、低冲突 | 正常权重 |
| 高证据、高冲突 | 降权 |

建议：

- 早期区间用于架构开发；
- 中间区间用于参数和 Prompt 验证；
- 最新区间一次性最终测试；
- 测试后不得再修改结论。

## 三十三、核心评价

这篇报告最重要的贡献不是证明“大模型可以选股”，而是展示如何把主题投研中的隐性步骤编码为多智能体研究协议：

```text
问题边界
+
产业链或宏观逻辑拆分
+
并行检索与分析
+
风险反证
+
证据仲裁
+
结构化组合输出
=
可执行的自动投研流程
```

概念智能体的核心价值在于把主题从模糊标签展开为产业链，并通过 Reviewer 检查覆盖与股票相关性；宏观热点智能体的核心价值在于让宏观、行业、股票与风险四条路径并行推演，再由 Evidence Judge 处理证据强度和冲突。两者共同体现出明显的 Research Process Alpha、Information Processing Alpha 和 Decision Consistency Alpha。
